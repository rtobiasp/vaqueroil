## Drizzle

Drizzle reads the schema from `src/db/schema.ts` and stores generated migrations in `supabase/migrations`. Configure `DATABASE_URL` in `.env.local` before using the database commands.

Generate a migration after changing the schema:

```bash
pnpm exec drizzle-kit generate
```

Apply pending migrations to the database:

```bash
pnpm exec drizzle-kit migrate
```

Open Drizzle Studio to inspect the database:

```bash
pnpm exec drizzle-kit studio
```

The database client is exported from `src/db/index.ts`. Keep `.env.local` out of version control because it contains the database connection string.
